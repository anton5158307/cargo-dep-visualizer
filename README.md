# Cargo Dependency Visualizer (Variant 15)

Инструмент визуализации графа зависимостей для Cargo.

## Запуск

python -m src.main config.xml

## Тесты

python -m unittest discover tests
## Сравнение с реальным менеджером пакетов (Cargo)



\*\*1. Порядок загрузки (Этап 4)\*\*

Штатная команда `cargo tree` выводит зависимости в виде иерархического дерева (сверху вниз). Наш инструмент использует топологическую сортировку, поэтому выводит зависимости в порядке, в котором их нужно собирать: сначала листья графа (те, от кого зависят другие), затем корень. Это объясняет расхождение в порядке вывода.



\*\*2. Визуализация (Этап 5)\*\*

Команда `cargo tree` выводит текстовое дерево. Наш инструмент генерирует диаграмму на языке D2, которая позволяет строить граф (в том числе с циклами, которые в Cargo запрещены, но могут быть в тестовых данных). Штатный менеджер не умеет генерировать D2 напрямую.
